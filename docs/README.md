# 근거자료 원문

앱이 산출 근거로 사용하는 원문 자료를 보관합니다.
파주시 내부망에서 외부 링크가 차단되는 경우에도 담당자가 근거를 확인할 수 있도록
사본을 앱에 함께 배포합니다.

| 파일 | 문서명 | 발행 | 분량 |
|---|---|---|---|
| `seoul-cost-guideline-2024.pdf` | 공공건축물 건립 공사비 책정 가이드라인 (2024) | 서울특별시 기술심사담당관 | 32쪽 |

## 연결 구조

`data/data.js` 의 `SOURCE_DOCS` 에 문서 정보를 두고, `UNIT_PRICE_DB` 각 단가 항목의
`page` 값으로 원문 쪽을 가리킵니다. `srcHref(key, page)` 가 `#page=N` 딥링크를 만들며,
브라우저 PDF 뷰어가 해당 쪽으로 바로 이동합니다.

- `office` p.6~7 / `culture` p.8·12·14 / `general` p.9~13 / `promo` p.8
- `complex`(복합시설)는 가이드라인 단가를 조합한 산출값이므로 쪽 번호를 두지 않습니다.

## 확인이 필요한 사항

- **재배포 조건**: 문서에 공공누리 유형 표기가 없습니다. 서울특별시 기술심사담당관에
  이용조건을 확인한 뒤, 제1유형(출처표시)이 아니라면 사본 배포를 원본 링크로 대체해야 합니다.
- **발행처 원본 URL**: 확인 후 `SOURCE_DOCS.seoul2024.origin` 에 기입하면
  사본과 원본을 함께 제공할 수 있습니다.
- **개정 주기**: 서울시가 격년 개정을 예고했습니다. 개정 시 PDF 교체와 함께
  `UNIT_PRICE_DB` 의 단가·`page` 를 재대조해야 합니다.

# 근거자료 원문

앱이 산출 근거로 사용하는 원문 자료를 보관합니다.
파주시 내부망에서 외부 링크가 차단되는 경우에도 담당자가 근거를 확인할 수 있도록
사본을 앱에 함께 배포합니다.

| 파일 | 문서명 | 발행 | 분량 |
|---|---|---|---|
| `seoul-cost-guideline-2024.pdf` | 공공건축물 건립 공사비 책정 가이드라인 (2024) | 서울특별시 기술심사담당관 | 32쪽 |

## 연결 구조

`data/data.js` 의 `SOURCE_DOCS` 에 문서 정보를 두고, `UNIT_PRICE_DB` 각 단가 항목의
`page` 값으로 원문 쪽을 가리킵니다. `srcHref(key, page)` 가 `#page=N` 딥링크를 만들며,
브라우저 PDF 뷰어가 해당 쪽으로 바로 이동합니다.

- `office` p.6~7 / `culture` p.8·12·14 / `general` p.9~13 / `promo` p.8
- `complex`(복합시설)는 가이드라인 단가를 조합한 산출값이므로 쪽 번호를 두지 않습니다.

## 구간 커버리지

원문의 **신축 단가 표 34개를 전부 반영**했습니다 (단가 카드 130개).
각 시설의 규모 구간과 순서 모두 원문 표와 같습니다.

| 유형 | 소분류 | 카드 | 포함 시설 |
|---|---|---|---|
| `office` | 6 | 23 | 동청사, 복지지원센터, 복합청사, 공공업무사무소, 119안전센터·소방서, 의회청사 |
| `culture` | 5 | 22 | 체육관·배드민턴장, 문화예술회관, 전시·박물관, 도서관, 청소년수련시설 |
| `general` | 8 | 78 | 사회복지관, 노인복지, 보건·의료(병원·산모건강증진센터 포함), 노유자시설, 자활작업장, 교육·연구, 기타 공공시설, 친환경 건축 |
| `promo` | 1 | 3 | 홍보관·전시관 |
| `complex` | 1 | 4 | 복합시설 — 위 단가를 조합한 산출값 |

`f_type` 은 투자심사상 사업유형(일반/청사/문화체육/복합/홍보관)이므로,
공중화장실·공영주차장·폐기물처리시설 같은 시설은 `general`(일반투자사업)에 속합니다.

카드가 유형당 최대 78개까지 늘어나, **소분류 단위로 접고 펼치는 방식**으로 정리했습니다.
추천 구간이 들어 있는 묶음만 펼쳐진 상태로 시작하고, 접힌 묶음도 구간 수와
단가 범위를 머리글에 보여줍니다. 담당자가 직접 펼친 상태는 유형을 바꿀 때까지 유지됩니다.

시설이 달라도 단가 값이 겹치는 경우가 있어(`general` 의 4,365·4,579),
선택 표시는 단가 값이 아니라 카드 위치 키(`unitKey`)로 식별합니다.

## 반영하지 않은 것

원문 p.17 이후는 성격이 달라 제외했습니다.

> 리모델링·개보수(p.17~18), 목조건축물(p.18), 철거공사비(p.19~20),
> 석면철거(p.21~22), 설계·감리 용역비(p.23~32)

앱의 단가 DB는 **신축 기준**이며, 증축(수평·수직) 단가도 원문에 있으나 사용하지 않습니다.

## 확인이 필요한 사항

- **재배포 조건**: 문서에 공공누리 유형 표기가 없습니다. 서울특별시 기술심사담당관에
  이용조건을 확인한 뒤, 제1유형(출처표시)이 아니라면 사본 배포를 원본 링크로 대체해야 합니다.
- **발행처 원본 URL**: 확인 후 `SOURCE_DOCS.seoul2024.origin` 에 기입하면
  사본과 원본을 함께 제공할 수 있습니다.
- **개정 주기**: 서울시가 격년 개정을 예고했습니다. 개정 시 PDF 교체와 함께
  `UNIT_PRICE_DB` 의 단가·`page` 를 재대조해야 합니다.
